## Что нового в 0.6.1

- **Приложения-пакеты MSIX и из Microsoft Store теперь в списке**, например Claude Desktop. У них нет обычных ярлыков в меню «Пуск», поэтому раньше они не находились.
- Блокируется весь пакет. Папка с версией меняется при каждом обновлении (`WindowsApps\Claude_<версия>_x64__…`), и S Tunnel находит новую папку и переносит блокировку на неё автоматически.

## 0.6.0

- **Блокируется приложение целиком, а не один .exe.** Основная программа, вспомогательные процессы, программа обновления и новые версии после обновления.
- **Выбор из списка установленных приложений** (по меню «Пуск») с поиском, без поиска .exe вручную. Можно отметить сразу несколько.
- Можно выбрать папку приложения вручную или, как раньше, отдельный .exe.
- Если после обновления в папке приложения появился новый .exe, он блокируется автоматически.
- Слишком общие папки (Program Files, Загрузки, Рабочий стол, профиль пользователя, весь диск) выбрать нельзя.

## 0.5.0

- **«Только через S Tunnel».** Выберите программы (Telegram, браузер, игровой клиент…), которые не должны работать без туннеля:
  - если запустить такую программу при выключенном туннеле, S Tunnel сразу её закроет и покажет уведомление; нажмите на уведомление, чтобы подключиться;
  - при отключении туннеля такие программы закрываются;
  - пока туннель выключен, брандмауэр не выпускает эти программы в интернет, даже если S Tunnel закрыт или не запущен, так что реальный IP не утечёт и в первые миллисекунды после запуска;
  - при удалении S Tunnel эти блокировки снимаются.
- Нельзя добавить системные программы Windows и приложения из Microsoft Store.

## 0.4.0 — исправления безопасности

- **Утечка через старые соединения.** TCP-соединения, открытые до подключения (мессенджеры, игровые клиенты, вкладки браузера), продолжали идти мимо туннеля с реальным IP. Теперь при подключении они принудительно закрываются, и программы переподключаются уже через прокси. В «Проверке утечек» появился пункт «Старые соединения мимо туннеля».
- **Подмена файла состояния kill switch.** Программа без прав администратора могла подложить свой `killswitch.json`, и при отключении S Tunnel выключил бы брандмауэр. Теперь в папку состояния могут писать только Администраторы и SYSTEM, содержимое файла строго проверяется, а брандмауэр по нему никогда не выключается.
- **Пароль прокси больше не лежит открытым текстом на диске.** Конфиг ядра записывается только на секунду запуска и сразу удаляется.
- Сохранённый IP прокси проверяется перед использованием.

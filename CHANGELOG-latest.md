## Что нового в 0.3.2

- **Исправлено:** ошибка «Не удалось восстановить брандмауэр… killswitch.json» при отключении. Повторное нажатие «Отключить» теперь ждёт уже начатое отключение, а команды брандмауэра выполняются строго по очереди.
- Ошибки брандмауэра показываются обычным текстом, без служебного формата CLIXML и испорченной кириллицы.
- Кнопка подключения и отключения блокируется, пока операция не завершится.

## 0.3.1

- **Исправлено:** ошибка подключения «set ipv4 address: The object already exists». Виртуальный адаптер теперь использует редкую подсеть, которая не пересекается с v2rayN, Hiddify, Nekoray и другими клиентами на sing-box. Перед каждым запуском удаляются адреса, оставшиеся после прошлого сбоя.
- Понятные сообщения об ошибках запуска ядра.
- Журнал без цветовых кодов.

## 0.3.0

- Обновление приложения из GitHub Releases, только через прокси.
- SOCKS5 с UDP через прокси, проверка UDP через STUN, выбор протокола.
